## Sites de Raspagem de Leilões

Os sites para raspagem (scraping) de leilões estão listados no arquivo [`sites.json`](sites.json).

O arquivo contém uma lista com todos os sites de leilões brasileiros cadastrados para raspagem de dados.

### Total de sites

O arquivo [`sites.json`](sites.json) contém atualmente **194 sites** únicos de leilões.
